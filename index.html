Internet Programming Course Summary

A practical course that starts from web foundations and gradually builds toward modern, API-driven, interactive web applications using HTML, CSS, JavaScript, TypeScript, Git, and GitHub Pages deployment.

Course Snapshot

  • Duration: 14 weeks

  • Tools: VS Code, browser DevTools, Git, GitHub
  • Outcome: Published interactive website

Course Purpose

What this course covers

🌐

Web Foundations

The course begins with the structure of the web: clients, servers, DNS, HTTP/HTTPS, static pages, dynamic pages, and modern web architecture.

🧱

Front-End Building Blocks

HTML5 is used for structure, CSS3 for layout and responsive design, and JavaScript for logic, interaction, DOM manipulation, and API communication.

🚀

Professional Workflow

The final part introduces TypeScript, version control with Git, GitHub workflow, and deployment through GitHub Pages.

Weekly Structure

14-week course roadmap

Use the filter buttons to focus on foundations, HTML/CSS, JavaScript, TypeScript, or deployment topics.

Introduces how the Internet works, client-server communication, DNS, HTTP/HTTPS, static pages, dynamic pages, and the basic path from entering a URL to receiving a webpage.

Covers three-tier architecture, RESTful services, JSON versus XML, API-driven applications, and how a webpage can become part of a distributed system.

Focuses on semantic HTML elements, document structure, forms, validation, multimedia elements, accessibility basics, and writing meaningful page markup.

Explains the box model, selectors, typography, colors, Flexbox, CSS Grid, media queries, and how responsive layouts adapt to different screen sizes.

Introduces JavaScript syntax, variables, data types, operators, template literals, arrow functions, and the role of ES6+ features in modern JavaScript development.

Builds programming logic with conditional statements, loops, functions, parameters, return values, scope, hoisting, and basic debugging habits.

Covers arrays, objects, array methods, destructuring, spread syntax, object manipulation, and using structured data to produce dynamic web content.

Connects JavaScript to HTML and CSS through the DOM. Topics include selecting elements, changing content and styles, creating new elements, and updating the page dynamically.

Explains event listeners, user actions, form events, default browser behavior, event objects, input handling, and building pages that respond to user interaction.

Introduces callbacks, promises, async/await, the Fetch API, HTTP requests, REST API consumption, and displaying external data inside a webpage.

Introduces the purpose of TypeScript, basic types, type inference, function typing, interfaces, optional properties, and why type safety helps prevent common JavaScript mistakes.

Applies TypeScript to realistic front-end tasks, including typed API responses, typed objects and arrays, safe DOM manipulation, and an overview of TypeScript tooling.

Covers Git fundamentals, commits, branches, merging, GitHub workflow, repositories, pull requests, project history, and hosting static websites through GitHub Pages.

Connects all course topics into a complete website project: structure, styling, interactivity, data use, version control, publishing, documentation, and final quality checks.

Practice Direction

Recommended lab progression

Early Labs

Build structured pages, inspect websites with browser DevTools, create forms, and design responsive layouts.

Middle Labs

Add JavaScript logic, work with arrays and objects, update the DOM, and create realistic user interaction.

Advanced Labs

Fetch external API data, type data models with TypeScript, manage a Git workflow, and publish the finished site.

fetch("https://api.example.com/items")

  });

Final Output

Suggested final project

The final project should be a published, responsive, interactive website that uses HTML, CSS, JavaScript, and API-based data. The project should be managed with Git and hosted using GitHub Pages.
